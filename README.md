# Reveal.js Wrap

## Synopsis

This repository is a small wrap and custom configuration collection for
[hakimel/reveal.js](https://github.com/hakimel/reveal.js). The `-wrap` suffix
marks it as an adaptation of the third-party stem, not the upstream project
itself and not a `-inst` of a personal tool.
